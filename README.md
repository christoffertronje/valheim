# Valheim Companion

A simple static website for Valheim tools, covering progression through Mistlands without later-biome spoilers.

## Pages

- `/` — Homepage
- `/food/` — Food recipes, filters, and ingredient calculator

## GitHub Pages

1. Create a **public** repository named `valheim`.
2. Add the contents of this folder to the repository root (not the enclosing `valheim-site` folder).
3. Open **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, `main`, `/(root)` and save.
4. The site will be available at `https://YOUR_USERNAME.github.io/valheim/` once deployed.

You can add more pages by creating new folders each with an `index.html`.
